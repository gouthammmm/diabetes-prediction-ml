# Diabetes Prediction Using Machine Learning

A machine learning project focused on predicting diabetes using patient health-related data and classification techniques.

## Tools & Technologies

* Python
* Pandas
* Scikit-learn
* XGBoost
* Machine Learning

## Project Work

* Data preprocessing
* Exploratory data analysis
* Feature preparation
* Machine learning model development
* Diabetes prediction
* Model evaluation

## Project Files

* `prediction of diabetes mellitus using xgboost.py` — Python machine learning implementation using XGBoost
* `Interface.txt` — Project interface and related content

## Objective

The project demonstrates the application of machine learning techniques to analyze health-related data and predict the likelihood of diabetes.
